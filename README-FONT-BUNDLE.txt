Offline Bengali font bundle
===========================

This project now includes FreeSerif Bengali-capable font files in the fonts/ folders.
The editor Font Family menu includes “FreeSerif Bengali (Offline Embedded)”. Select it to use a bundled font without installing anything in Windows or needing internet access.

The HTML templates also load the bundled FreeSerif font first. Background images and existing project layout were preserved.

Important: FreeSerif is a bundled fallback Bengali font. It may not be visually identical to a source PDF that uses a different font such as Nikosh or SolaimanLipi. This package cannot guarantee exact matching to a PDF unless the original font file is available. FreeSerif license/copyright information is included beside the font files.
