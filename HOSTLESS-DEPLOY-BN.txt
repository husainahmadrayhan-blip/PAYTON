HOSTLESS DEPLOY GUIDE (বাংলা)
============================

এই ZIP-এ Hostless-এর জন্য Dockerfile যোগ করা হয়েছে এবং মূল server.py-কে cloud PORT-এ listen করার মতো করা হয়েছে। /api/health health-check endpoint-ও যোগ করা হয়েছে।

Deploy করার ধাপ
---------------
1. ZIP extract করুন।
2. পুরো project GitHub repository-তে upload/push করুন (সব ফাইল ও subfolder রাখবেন)।
3. https://web.hostless.cloud/ এ যান এবং GitHub দিয়ে sign in করুন। কার্ড ছাড়া free tier শুরু করা যায়—বর্তমান allowance Hostless-এর সাইটে যাচাই করুন।
4. New Project / New App থেকে GitHub repository নির্বাচন করুন।
5. Build System হিসেবে Dockerfile নির্বাচন করুন; Dockerfile path হবে ./Dockerfile; Working Directory হবে repository root (/).
6. App deploy করুন। সফল হলে Hostless একটি HTTPS URL দেবে।
7. Health check: আপনার URL-এর শেষে /api/health যোগ করে খুলুন। JSON-এ {"ok": true} দেখা উচিত।

গুরুত্বপূর্ণ সীমাবদ্ধতা ও নিরাপত্তা
--------------------------------
- Free tier-এর CPU/RAM/storage সীমিত। Playwright, OpenCV এবং PDF extraction একসঙ্গে চালালে resource limit ছাড়াতে পারে।
- Projects API-তে save/open/delete route আছে। এই সংস্করণে সেগুলোতে user login/authentication যোগ করা হয়নি। Public URL শেয়ার করার আগে authentication না যোগ করলে অচেনা ব্যবহারকারী project data পড়তে, বদলাতে বা মুছতে পারে। সংবেদনশীল PDF/ID data দিয়ে ব্যবহার করবেন না।
- Container-এর local filesystem স্থায়ী storage নয়—redeploy/restart হলে projects হারাতে পারে। Hostless-এ persistent volume/storage সুবিধা থাকলে /data mount করুন এবং Environment Variables-এ PROJECTS_DIR=/data/projects সেট করুন। এই সুবিধা আপনার plan/account-এ আছে কি না যাচাই করুন।
- বর্তমান server-এ save API-র ZIP upload limit 100 MB এবং PDF extraction limit 25 MB।
- এই ZIP-এর cloud deploy বাস্তবে চালিয়ে পরীক্ষা করা হয়নি; প্রথম deployment-এর Logs দেখে dependency/build error ঠিক করতে হতে পারে।
